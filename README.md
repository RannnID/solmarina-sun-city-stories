SOLMARINA — Sun City Stories is an original open-world crime game built for the make.fun gta6-01 bounty. Explore a sun-soaked 9×9-block city on foot and by car, steal cars, dodge traffic and pedestrians, build a wanted level and outrun police chases, and play through 8 story missions with combat, a HUD and a minimap. Built with three.js; it runs in desktop Chrome from static files with no build step — open http://localhost:8080 after starting the server below.

## Run it

```sh
node serve.ts
```
